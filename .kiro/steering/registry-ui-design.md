# Registry UI Design System

When working on any file under `apps/registry/`, follow the Wise-inspired design system documented in `apps/registry/DESIGN.md`.

Key rules:
- Primary CTA color: `#9fe870` (lime green) — the only brand accent
- Card and button radius: 24px (`rounded-xl`)
- Page backgrounds: sage `#e8ebe6`, cards: white `#ffffff`
- Typography: Inter weight 800–900 for display, 400–600 for body
- Elevation via surface contrast (sage vs white), not shadows
- Spacing base unit: 4px; card padding: 24px; section padding: 48px
- Status badges: pill-shaped with semantic colors
- Form inputs: 12px radius, 1px ink border, green focus ring
